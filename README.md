# Lifeplan Simulator

家族のライフプランとお金の流れを、生涯にわたって月ごとに試算する Web アプリです。

- 月ごとの値ではなく「いつ何が起きるか」（出産・育休・時短・住宅購入・定年・年金など）を入力すると、月次のキャッシュフローに展開します。
- 額面年収から手取りを計算し、税・社会保険を自動で反映します（2025〜2026年の制度にもとづく概算）。対象は所得税・住民税・社会保険料、年末調整（iDeCo・生命保険料・地震保険料の控除）、住宅ローン控除、退職所得（退職金・iDeCo の一時金）、NISA の非課税枠、譲渡益課税、児童手当、育児休業給付です。
- 公的年金は給与の履歴から自動で概算します（加給年金・在職老齢年金・繰上げ／繰下げを含む）。
- 固定資産税は物件価格から自動で概算します。
- 「シナリオ比較」で、子どもの人数（0〜4人）・住まい（賃貸のまま／家を買う）・配偶者の働き方（会社員を続ける／出産を機に退職／パート／働かない）の組み合わせを自動で作り、資産の推移や教育費・住居費・生涯の手取りを並べて比べられます。気になるパターンはプランとして保存できます。
- 「結果」画面の「効果が大きい見直し」で、生活費・働く期間・NISAの積立・年金の受け取り開始・住宅価格・車などを1つずつ変えたときの効果を、大きい順に示します。
- iDeCo・企業型DC の受け取り方（一時金・年金・併用）、企業型DCのマッチング拠出、持株会の奨励金、親や自分たちの介護費用も見込めます。
- 利回り・インフレ率・昇給率・支出・年金額を動かして、その場で結果を確かめられます。
- 「いまの物価」に換算した表示、年ごとの収入・税・支出・口座の内訳、モンテカルロによる運用リスクの試算ができます。
- 「万一の備え」で、遺族年金・団信・死亡保険金を反映した資金推移と必要保障額を試算できます。
- 「計算の前提」画面に、使っている制度と数字をまとめています。
- 入力したデータと計算はすべてブラウザの中で完結し、サーバーには送信しません。プランはファイルへの保存・読み込み（追加または置き換え）と、プランをリンクの `#` 以降に入れた共有リンク（サーバーには送られません）で受け渡せます。
- 保存データが読めない・計算できない場合も画面全体が止まらないようにし、読めなかったデータは消さずに残します。しばらくファイルに保存していないときは保存を促します。

仕様は [docs/spec.md](docs/spec.md) を参照してください。

> 結果は試算であり、金融・税務の助言ではありません。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173/lifeplan-simulator/
npm test         # 計算エンジンのテスト
npm run build    # dist/ に静的ファイルを出力
```

### 構成

| パス | 内容 |
| --- | --- |
| `src/engine/` | 計算エンジン（UI に依存しない純粋な TypeScript） |
| `src/engine/tax.ts` | 所得税・住民税・社会保険・各種控除・退職所得 |
| `src/engine/benefits.ts` | 児童手当・育児休業給付 |
| `src/engine/education.ts` | 教育費の既定値（文部科学省「子供の学習費調査」ほか） |
| `src/engine/housing.ts` | 住宅ローンの返済表、固定資産税の概算 |
| `src/engine/pension.ts` | 公的年金（老齢・加給・在職老齢・遺族） |
| `src/engine/simulate.ts` | 月次シミュレーション本体 |
| `src/engine/montecarlo.ts` | 運用リスクの試算（乱数で相場を再現） |
| `src/engine/risk.ts` | 万一のときの試算と必要保障額 |
| `src/engine/wizard.ts` | かんたん入力の回答からプランを組み立てる処理 |
| `src/engine/scenarios.ts` | 子どもの人数・住まい・働き方を変えたパターンの作成 |
| `src/engine/hints.ts` | 効果が大きい見直し（1つずつ条件を変えたプラン） |
| `src/engine/validate.ts` | 読み込んだプランの検査（形式と、実際に計算できるか） |
| `src/engine/sample.ts` | 初回に表示するサンプル世帯 |
| `src/ui/` | 画面（React） |
| `src/ui/share.ts` | 共有リンクの作成・読み込み（圧縮して URL の `#` 以降に入れる） |

## 公開

`main` ブランチに push すると、GitHub Actions がテストとビルドを行い、GitHub Pages に公開します（`.github/workflows/deploy.yml`）。
初回だけ、リポジトリの Settings → Pages で Source を「GitHub Actions」にしておく必要があります。
